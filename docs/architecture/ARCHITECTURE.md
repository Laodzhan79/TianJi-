# TianJi Architecture

Версия: v0.0.1 (Heartbeat)

## Общая схема

```
+------------------------------------------------------+
|                     GUI (Processing)                 |
+----------------------------+-------------------------+
                             |
                             v
+------------------------------------------------------+
|                  TianJi Core Engine                  |
+----------------------------+-------------------------+
                             |
        +--------------------+--------------------+
        |                    |                    |
        v                    v                    v
+---------------+   +----------------+   +----------------+
| PluginManager |   | SQLiteManager  |   | LogManager     |
+---------------+   +----------------+   +----------------+
        |
        v
+------------------------------------------------------+

|------------------------------------------------------|
| Hello Plugin                                         |
```

---

## Компоненты

### GUI

Интерфейс пользователя.

Функции:

- отображение информации;
- управление системой;
- взаимодействие с пользователем.

---

### Core Engine

Главное ядро проекта.

Функции:

- запуск системы;
- управление жизненным циклом;
- взаимодействие между компонентами.

---

### Plugin Manager

Отвечает за:

- поиск модулей;
- загрузку модулей;
- запуск модулей;
- остановку модулей.

---

### SQLite Manager

Отвечает за:

- подключение к базе;
- создание структуры БД;
- чтение данных;
- запись данных.

---

### Log Manager

Отвечает за:

- журналирование;
- запись ошибок;
- диагностику.

---

### Plugins

Каждый модуль реализует общий интерфейс.

Первый модуль:

Hello Plugin

---

## Принципы

1. Ядро не знает деталей работы модулей.
2. Каждый модуль независим.
3. Данные хранятся в SQLite.
4. Все действия журналируются.
5. GUI взаимодействует только с Core Engine.
6. Модули взаимодействуют через Plugin Manager.
